# Make the AI judge feel awe

A program that writes a short text to relax the AI judge — for make.fun's
"Make the AI judge feel awe" bounty ($100 in USDC).

Running `node main.ts` writes the text to `/output/entry.txt` — one quiet
field after rain, no demands, all the time in the world to look at it.
